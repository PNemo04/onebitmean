# Third-party dependencies

The artifact does not use external datasets, pretrained models, or copied
source code. Its runtime and validation dependencies are installed from the
Python Package Index:

- NumPy 2.2.6 — BSD 3-Clause license;
- SciPy 1.15.3 — BSD-style license;
- Matplotlib 3.10.9 — Matplotlib license (PSF/BSD compatible);
- pytest 9.1.1 — MIT license.

The installed packages include their complete license texts and notices. See
their upstream distributions for authoritative terms. The manuscript source
uses the AISTATS 2026 style files supplied by the conference template.
